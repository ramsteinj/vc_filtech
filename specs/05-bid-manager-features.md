# 05. 입찰담당자 기능

## 1. 로그인
`/login`, ID·비밀번호. [03](03-auth-and-access.md) 참조.

## 2. 대시보드 + 공고 목록 (`/`)

### 2.1 상단 대시보드 카드 (3개)
| 카드 | 값 | 클릭 시 |
|---|---|---|
| 총 입찰 건수 | 전체 공고 수 | 필터 해제 |
| 확인 건수 | `review_status=REVIEWED` | 목록 필터 |
| 미확인 건수 | `review_status=UNREVIEWED` | 목록 필터 |

`GET /api/dashboard/summary` → `{total, reviewed, unreviewed}`. (현재 필터와 무관한 전체 기준)

### 2.2 하단 공고 목록
- 컬럼: 확인 상태 배지, 공고번호, 공고명, 수요기관, 입찰 마감일시(D-day), **적합도**(0–100 바 + 색), 판정 요약(충족/보완/확인 개수 미니 배지), 매칭 제품, 처리 상태, 낙찰 결과.
- 기본 정렬: 미확인 우선 → 마감일 임박 순. 정렬 변경 가능(적합도, 등록일).
- 필터: 확인 상태, 발전소 공고만, 적합도 ≥ N, 마감 전/후, 낙찰 결과, 검색어(공고명·수요기관·공고번호).
- 페이지네이션 20건.
- 마감 지난 공고는 회색 처리.

## 3. 공고 상세 (`/bids/:id`)

상단: 공고 헤더(공고명, 공고번호, 수요기관, 마감일시, 사업금액/추정가격, 입찰방법, 적합도, 확인 상태) + 버튼 [확인 완료 / 확인 취소], [판정 재실행], [PDF 다운로드].
본문은 **5단계 탭(스텝)** 구조. 각 탭은 독립적으로 열람 가능.

### ① 핵심 요구사항
- 공고 요약(LLM summary), 공고 개요 표(일정·금액·납품·하자·자격).
- 품목 표(품번, 품명, 규격, 수량, 매칭 제품 후보).
- **요구사항 표**: 카테고리 그룹(제품 치수 / 필터 형식 / 필터 등급 / 효율 / 차압 / 풍량 / 재질 / 시험규격 / 인증·자격 / 납품실적 / 납기 / 제출서류 / 하자 / 검사 / 기타), 품목별 그룹 토글. 각 행: 요구 내용, 필수 여부, 출처(첨부명·페이지) — 클릭 시 원문 인용 팝오버.
- 최소 표시 카테고리(요구사항 명시 항목): 제품 치수, 필터 등급, 효율, 차압, 필요 시험규격, 인증, 납기, 제출서류.
- 첨부파일 목록 및 다운로드.

### ② 회사 자료 비교
- 품목별로 매칭 제품(1순위 + 대안 최대 2개) 선택 드롭다운 — 담당자가 바꾸면 해당 품목 요구사항 재판정 제안.
- 비교 표: `요구사항 | 요구값 | 회사 제품 사양 | 시험성적서 | 인증 | 납품실적` — 각 셀은 근거 문서 링크(성적서 번호 클릭 → 문서 뷰어).
- 공통 요구사항(자격·서류)은 회사정보/인증서/실적과 비교.

### ③ 판정 및 자동 답변
- 각 요구사항 행: **판정 배지**(충족=녹색, 보완 필요=주황, 확인 필요=회색/파랑) + 위험도(HIGH 빨간 점), **판정 근거**(rationale + evidence 목록), **자동 답변**(auto_answer), 보완 조치(action_items), 확인 필요 시 질의 문안.
- 상단 요약: 충족 n / 보완 필요 n / 확인 필요 n, HIGH 위험 n.
- **수정**: 판정 드롭다운, 답변·근거·조치·질의 텍스트 편집(인라인 또는 모달). 수정 시 “수정됨” 표시, 원본 AI 판정 보기, “AI 판정으로 되돌리기”. 이력(EvaluationHistory) 보기.
- 행 단위 “이 항목만 재판정”, 전체 “판정 재실행”(수정된 항목은 유지 옵션 기본 ON).
- 판정 Job 실행 중이면 진행률 표시.

### ④ 초안 생성
- 카드 4개: **Compliance Matrix**, **입찰 체크리스트**, **발주처 기술질의서**, **검토 보고서**. 각 [생성 / 재생성] 버튼, 최신 버전·수정 여부·생성일 표시.
- 생성은 Job. 판정 수정 내용이 반영됨. 재생성 시 기존 수정본이 있으면 “새 버전으로 생성”(이전 버전 보존).
- 형식은 [09](09-drafts-and-reports.md).

### ⑤ 결과 확인 · 수정 · 다운로드
- 초안별 편집 화면: 표 형식 초안은 셀 편집 가능한 표(행 추가/삭제), 텍스트 섹션은 textarea(간단 마크다운).
- 저장(같은 버전 덮어쓰기, `is_modified=True`), 버전 목록·이전 버전 보기.
- **PDF 다운로드**: 개별 초안 PDF, 또는 “통합 보고서 PDF”(공고 개요 + 요구사항·판정 + 4개 초안). 가능하면 XLSX(Compliance Matrix, 체크리스트)도 제공 — 선택 기능.
- [확인 완료] 처리: 공고 `review_status=REVIEWED`, `reviewed_by/at` 기록 → 대시보드 확인 건수 반영. 확인 취소 가능.

## 4. 권한상 제한
- 입찰담당자는 공고 메타데이터·요구사항 자체를 수정할 수 없다(관리자 기능). 요구사항이 잘못 추출된 경우 “요구사항 수정 요청” 메모를 남길 수 있다(선택 기능, `BidRequirement`에 대한 코멘트).
